JavaScript IF/ELSE Statements

What are IF/ELSE Statements?

IF/ELSE statements allow JavaScript to make decisions. An IF statement runs when something is true, and an ELSE statement runs when it is false.

How to Write an IF Statement?

An IF statement checks if something is true. If it is, the code will run. 

let temperature = 32;

if (temperature > 30) {
  console.log("It's hot outside!");
}
Since the temperature is 32, the condition is true and the message shows up.
How to Write an ELSE Statement?

An ELSE statement runs when the IF condition is not true. 

let age = 15;

if (age >= 18) {
  console.log("You can vote.");
} else {
  console.log("You cannot vote yet.");
}
Since the age is 15, the ELSE message will show up instead.
How to Write an ELSE IF Statement?

An ELSE IF statement lets you check more than one condition. 

let score = 85;

if (score >= 90) {
  console.log("Grade: A");
} else if (score >= 80) {
  console.log("Grade: B");
} else if (score >= 70) {
  console.log("Grade: C");
} else if (score >= 60) {
  console.log("Grade: D");
} else {
  console.log("Grade: F");
}
Since the score is 85, the message "Grade: B" will show up.
